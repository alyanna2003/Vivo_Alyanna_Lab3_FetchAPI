1. What are the main differences between XMLHttpRequest and Fetch API?

XMLHttpRequest is an older JavaScript method for making HTTP requests and usually uses event handlers such as onreadystatechange. Fetch API is a newer method that uses Promises, making it easier to write and understand asynchronous requests.

2. Why is the Fetch API considered more modern and readable?

The Fetch API is considered more modern and readable because it uses Promises and has a simpler syntax. It makes asynchronous code easier to organize and understand compared to XMLHttpRequest.

3. What is the purpose of the .then() and .catch() methods in Fetch?

The .then() method is used to handle the successful result of a Fetch request. The .catch() method is used to handle errors that occur during the request or while processing the response.

4. What happens when you send a POST request to the placeholder API?

When a POST request is sent to the placeholder API, the server receives the data and returns a simulated response containing the newly created post information. The response includes an ID, which is 101 for this example.
